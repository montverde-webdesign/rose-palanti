My font

Rules I wrote

Rule 1

body {
    font-family: courier, monospace;
    background-color: #fcc5ce;
    font-size: 20px;
    line-height: 1.6;
    margin: 10px;
    
}
a {
    color: rgb(255, 0, 140);
    text-decoration: double;
}
h1, h2, h3, h4, h5, h6 {
    color: rgb(252, 249, 251);
    font-weight: bold;
    font-size: 50px;
    border-bottom: 5px solid rgb(250, 249, 249);
}
:root {
    --main-bg-color: rgb(252, 197, 206);
    --main-font-color: #fcf9fb;
    --link-color: #ff008c;
}
a:hover {
    color: rgb(253, 253, 253);
    text-decoration-color: rgb(7, 6, 6);
    text-decoration-style: underline overline wavy #111113;
    text-decoration-thickness: 10px;
}

Without it, my page would not be organized or colorful.
